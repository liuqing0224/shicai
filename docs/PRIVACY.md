# 隐私与合规说明

## 数据边界

本项目处理招聘简历，可能包含联系方式、教育及工作经历等个人信息。仅在已有招聘授权、明确职位目的和必要范围内处理。采集范围限定为运行者可访问的候选人评估列表，职位名称必须精确匹配。

浏览器会话保存在 `.data/feishu-profile`，候选人缓存保存在 `collector/output`。两者均已排除版本控制，但仍属于敏感数据。不得上传公共代码仓库、共享网盘、日志平台或发送给无招聘职责人员。

## 安全要求

- 不复制、打印、导出或记录 Cookie、会话令牌和请求鉴权头。
- 资料目录和输出目录仅授权招聘相关人员访问；建议使用全盘加密和受控系统账户。
- 服务端日志只记录批次 ID、候选人内部/外部 ID 和状态，不记录简历正文、联系方式或模型完整输入。
- 传输到非本机模型或服务前，确认组织授权、数据处理协议、保存期限和数据所在区域。
- 为候选人缓存、模型输入输出和评估结果设置书面保存期限；到期后安全删除，包括备份副本。
- 若候选人请求查阅、更正或删除资料，应能通过 `source=feishu` 与 `externalId` 定位全部相关记录。

## 自动评估边界

自动评分和面试指南只能提供职位相关的辅助信息，不能代替招聘人员作最终决定。解析、评估、复核和面试设计 Agent 均不得使用或推断年龄、性别、种族、民族、国籍、宗教、残障、健康、怀孕、婚育、性取向、政治面貌、外貌等受保护属性。

职位标准应在查看候选人结果前确定并留存版本。每个结论必须能回溯到职位要求和简历证据；证据缺失应标记为未知，而不是自动判定不满足。人工复核者应能查看评分构成、修正错误并覆盖系统建议。

面试问题不得要求前雇主机密、源代码或内部数据。强信号和预警信号只用于指导现场核验，不能脱离候选人回答单独形成录用结论。

## 最小化原则

采集器只调用候选人列表、默认简历和解析正文的读取接口，不改变飞书中的候选人阶段、标签、评价或消息。下游评估不需要的联系方式、证件号码、详细住址和照片不得进入评分提示词。新增字段或外部集成前应重新评估是否必要，并更新本说明。
